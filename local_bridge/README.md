# 本地桥接与预测账本

首版只读取本机 MT5，不会下单。`mt5_reader.py` 获取 M5、M15、M30、H1 K线、Bid/Ask 与点差；指标计算、新闻抓取和模型分析接在快照之后。`prediction_ledger.py` 冻结每次预测，并在下一固定时点使用真实区间结算。

正式评估固定为北京时间 08:30、15:00、20:00，每份统一观察4小时。每轮先结算到期预测，再生成新预测；手动运行使用 `manual` 标签并排除正式胜率。旧两小时样本保留但不混入 `session-3x-v1` 统计。新闻必须保存标题、来源、发布时间、首次抓取时间和 URL，只能使用 `cutoff_at` 前可见内容。

系统从MT5成交历史只读统计北京时间当天的XAUUSD开仓成交。达到2次后强制输出空仓；如果历史读取失败，也保守暂停新交易建议。系统不调用下单接口。

GitHub 只保存源码和脱敏后的网页数据。MT5 账号、邮件口令、飞书 Webhook、模型 API Key 放在本机环境变量或 GitHub Secrets，禁止提交。首版推荐由 Windows 任务计划运行本地桥接，再把脱敏 JSON 推送到私有仓库或受保护的数据服务。
